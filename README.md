# ChessVariants

Хаб необычных шахматных вариантов. Открой `index.html` (или подними любой статический сервер) и выбирай вариант.

## Варианты

- **Классика** — обычные шахматы.
- **Слабое звено** — фигура берёт только фигуру своего достоинства или ниже (пешка — только пешку, ферзь — кого угодно).
- **Двойной ход** — за ход делается два хода подряд.
- **Вращающаяся доска** — каждые 4 полных хода доска поворачивается на 90°, пешки меняют направление.
- **Хамелеон** — походившая фигура превращается по циклу Ф→Л→С→К→П→Ф.

Режимы: против компьютера (ИИ на негамаксе с альфа-бета-отсечением, глубина 3, позиционные оценки) или вдвоём на одном экране — доска при этом поворачивается к текущему игроку. Фигуры — стандартный набор cburnett как на lichess (SVG из репозитория lila).

## Запуск

```
python3 -m http.server 8000
```
